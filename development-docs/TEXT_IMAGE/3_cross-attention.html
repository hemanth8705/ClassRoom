Cross-Attention: Where the Prompt Meets the Picture

We have two lists of rows: one for the prompt, one for the canvas. This page shows what happens when they meet. Everything is computed live from tiny, hand-made numbers, so you can follow every multiplication.

INPUTS

What goes in

Three tables arrive at this step. (Colours: blue = positive number, orange = negative, stronger colour = bigger number.)

1. Positive word grid

The prompt "red car beach sunset", already turned into numbers by the text model. One row per token, D numbers per row.

2. Negative word grid

The negative prompt "blurry low quality", turned into numbers the same way. It goes through exactly the same machinery in its own separate run, so this page lets you switch between the two grids later.

3. Image tokens

The canvas, flattened into a list of rows (previous page). Here we use a tiny canvas of 4 columns × 3 rows = 12 cells, so N = 12 tokens, each a row of W = 4 numbers.

Cell colours are only a hint of what each cell is turning into. Midway through generation a cell already carries a rough idea of its content; we made these hints by hand.

Toy sizes. A real model has hundreds to thousands of tokens and rows thousands of numbers wide. We use D = 6, W = 4, N = 12, T = 4 so you can see every number. The mechanism is identical.
STEP 0

First, give the text the same width as the image

The image rows are W = 4 numbers wide, the text rows are D = 6 wide. Rows can only be compared if they have the same length, so the text goes through one learned table of size D × W, exactly like the C → W table on the previous page.

Learned table D × W (6 × 4)
Result for the whole grid

The same table is used for every token, just like the image side. The text now has shape [T, W], the image has [N, W]. Same row length.

Q, K, V

Where Q, K and V fit in

Comparing rows takes two small ideas. First, each side makes a short label row to be matched, and the text also makes a content row to be handed over. Three more learned tables do this:

  • Q (query) comes from the image cell. It is that cell's question: "which kind of word do I need?"
  • K (key) comes from the text token. It is the label the word shows off, so questions can be matched against it.
  • V (value) comes from the same text token. It is the content that gets copied into the cell if the cell picks that word.
  • Q and K must have the same length d so they can be compared. Here d = 2, small enough to draw on a flat sheet of paper (below). Real models use something like 64 to 128.
  • Why a separate K and V for the same word? A word can be easy to find (K) without handing over the same thing it is found by (V). Having two separate tables lets the model learn each job on its own.
Wq [W, d]
Wk [W, d]
Wv [W, d]
Q = image tokens × Wq, shape [12, 2]
K = text tokens × Wk
V = text tokens × Wv

These three tables are made up for the demo; in a real model they are learned during training.

THE FOUR STEPS

The recipe

  1. Scores. Compare each cell's Q with every word's K. A big number means a good match. [N, d] × [d, T] → [N, T]
  2. Softmax. Turn each cell's scores into percentages that add up to 100%. [N, T] → [N, T]
  3. Mix. Each cell takes that percentage of every word's V and adds them up. [N, T] × [T, d] → [N, d]
  4. Update. Widen the mix back to W numbers with one more learned table, and add it to the cell's own row. [N, d] × [d, W] → [N, W]

The next section runs all four on a single cell. Then the whole attention table shows every cell at once.

ALL CELLS AT ONCE

The whole attention table

The same four steps run for every cell at the same time. That is just one matrix multiplication. The result is a table of N rows (cells) × T columns (words) of percentages. Click a row to select that cell above.

Rows add up to 100%. Change the text grid or the √d box above to see them change. Top-row cells lean toward "sunset", middle cells toward "car", bottom cells toward "beach", because we gave their Q's those directions.

RECAP

What just happened

image tokens X [N, W] text tokens Tw [T, W] (after step 0) Q = X x Wq [N, d] what each cell asks K = Tw x Wk [T, d] what each word offers V = Tw x Wv [T, d] what each word hands over scores = Q x K^T [N, T] weights = softmax(scores) [N, T] each row adds to 100% mixed = weights x V [N, d] X_new = X + mixed x Wo [N, W] same shape as the input
  • The prompt is never pasted onto the picture. Every cell chooses how much of each word to take.
  • Only the image rows change. The text rows stay as they are.
  • The output has the same shape as the input, so another layer can follow, and another. The model repeats this inside every layer, and the whole stack is run again at every denoising step. The prompt grid is the same each time, but the cells have changed, so the percentages change too.
What this page simplifies. Real models split d across several parallel heads (each head has its own Wq, Wk, Wv and can attend to something different, like colour or place). They also add self-attention (cells looking at each other) and a per-token network next to this step. We also made up all the numbers, and a real model's attention is far less tidy. We have not checked LTX's exact layer layout, so treat this as the general idea.
