The Architecture, Pixel by Pixel

One picture of the whole text-to-image machine. Click any box in the diagram (or the numbers under it) to see what it does to a real 128 × 128 pixel canvas. No calculations here, only what changes and where.

How to read the pixels. The picture is 128 × 128 pixels. It is cut into 16 × 16 = 256 cells, each covering an 8 × 8 block of pixels (a real model cuts much coarser, around 32 × 32 pixels per cell, but then you'd only see a handful of cells). Also, a real model's noise and cells live in a compressed "latent" form, not in pixels. We draw them as pixels so you can see what each cell stands for. Attention maps below are hand-set from the picture's regions to be readable; real ones are messier.
